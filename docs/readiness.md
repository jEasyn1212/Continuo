# 0.7 可用性与首个真实流程

App/Web/CLI/MCP 经 continuo-core 的 Service::call 和共享目录，当前仅三个 agent 适配器。六大领域平行建设。“可用”指实际记录、领域校验、接口与隔离流程，不表示正式发布或已经操作用户原生运行时。

| --- | --- | --- |
| 身份 | 角色/指引、偏好 agent、能力/MCP 关联、本机当前身份 CAS、失效检查、并发合并 | 账号登录、对象级 ACL、操作系统安全隔离；指引不是权限 |
| 任务 | 目标/验收/下一步、六态/原因、进展/检查/决策/产物、版本绑定接续材料 | 原生自动采集、进程调度、工作目录文件同步 |
| 能力 | rule/skill 文本、来源/许可/版本、精确正文检查、依赖校验、三个适配计划 | 资源/脚本技能包、原生投递/回滚、实际 agent 验收 |

设备登记目前是元数据，未完成设备信任与撤销。配置、密钥、原生映射、账号引用、检查结果、SQLite 与原生状态不作为可携带配置上传。已在全部可携带对象和嵌套扩展中拒绝已知秘密/本机/运行字段及其大小写、下划线、连字符变体；自由正文和任意自定义字段无自动秘密/路径识别，上传前仍需核对内容。

旧客户端已保存的违规历史保持本机可读；同步预检与交换在连接远端前拒绝它，不自动删字段、改写 revision 或丢弃因果历史。更新后的客户端不能单独修复这类旧历史；需另行设计并批准迁移范围。真实双设备试用前，两端需核对相同源码 commit，不能只看 0.7.0 版本号。

## 验证分层

Rust 工作空间测试覆盖并发、重复上传、断网、未来版本、密文篡改/错误密钥、历史缺失、停用、取消/超时及删除恢复。CLI/MCP worker 与 Web 桥接分别验证取消响应，共享 React 表单操作真实服务与临时存储。Tauri 独立检查与 macOS arm64 ad-hoc 构建单独验证。

本版像素/窗口视觉尚未验收：工具连接 Mini 锁屏，未绕过；用户只确认过之前版本可见。jsdom、构建、Air 进程/接口核验不能替代窗口验收。公开分发还缺 Developer ID、公证、安装/更新器、跨平台与安全审计。

## 建议首个完整实际流程

目的：Mini 登记真实目标和身份，Air 读取同版并追加进展，Mini 拉回；验证并发整理、删除传播和恢复。三个 agent 先核验接续材料/参数，不自动运行。

1. 用户指定已有专用私有 GitHub 数据仓库，与公开代码仓分离；仅操作 continuo-sync 分支，不强推。
2. Mini 建隔离目录 ~/Documents/Continuo-Pilot/data 和 ~/Documents/Continuo-Pilot/secrets；Air 相同相对路径。不复用演示数据、不读取私人 profile/原生日志。
3. Mini 私密目录生成新工作区密钥，权限 600，经已核验 SSH 转交 Air 对应文件。不进入 Git、不输出原始密钥。不替换已有密钥。
4. 两端分别配置仓库和本机密钥。使用已配置 Git 认证，只验证对此仓库必要读写，不读取/打印 token、不新增 OAuth 或扩大账号权限。
5. 两边先预检；若远端已有内容或格式/密钥异常则停止，不能用新密钥覆盖。Mini 创建本人确认的非敏感身份/任务并上传；Air 拉取核对，追加实际进展再上传；Mini 拉回核对。
6. 离线分别改同一记录，保留两个 head 后显式整理；删除后 Air 拉取，选历史恢复，再回 Mini 验证新 parent 和完整历史。原演示目录保持。
7. 两端启动单独且仅监听回环地址的试用 Web，明确授予隔离目录 writes/admin/sync；不修改原 Air 演示权限。核验 App/Web/CLI/MCP 共享状态。

### 开始前需明确的授权范围

需要用户提供已有专用私有仓库 URL，并授权以上两台的新目录/私密文件创建、仅该仓库网络读写、Mini→Air 密钥 SSH 转交、单独本机试用进程 writes/admin/sync。当前未执行，没有创建真实仓、使用 token 或提升演示权限。

实际 agent 运行另需选定 agent、cwd、可访问文件、账号环境、具体命令与原生配置变更范围。参数计划不等于进程执行、读取历史或写配置许可；本轮先完成可审查计划，不默认申请全部私人环境权限。

## 0.7 后源码阶段

已完成源码层 [受管配置投递/回滚](managed-deployment.md) 和 [内置模拟生命周期](managed-processes.md)：共享 App/Web 页面及 CLI/MCP 可调用。只在当前 vault 内生成单个 MCP 配置的新 home；模拟运行支持启动、状态、输出上限、停止、超时、监管者丢失后的显式中断恢复。真实 agent 执行、个人配置合并、账号隔离仍未实现，Air 0.7 演示尚无本阶段二进制更新。

真实同步及建立持续访问的新凭据/密钥必须专门批准或由用户交接；前面的试用计划是拟议范围，不是既有开发授权。本阶段审查修复、权限表、Air 差异与剩余验收依赖见 [收尾核对](review-closeout.md)。
