## 权限与“成功”的含义

| 入口 | 默认领域写入 / 管理 | 默认同步 | 命令检查 / 进程启动 |
| --- | --- | --- | --- |
| CLI 本机调用 | 开启 / 开启，作为本机用户工具 | 关闭，需 --allow-sync | 分别需 --allow-mcp-probes / --allow-managed-processes，核心另查确认与版本 |
| MCP / 普通 Web | 关闭 / 关闭，分别显式开放 | 关闭，网络同步另需 writes | 分别显式开放，另需 writes/admin；不得由 JSON 请求扩权 |
| Native App | 开启 / 开启，作为本机用户应用 | 具备能力，仍需用户配置且显式操作 | 常驻 probes/processes 关闭，确认的请求才授予本次能力；目录展示可确认操作不等于持续执行权限 |
| Air 已交付 Web | 开启 / 开启 | 关闭 | probes 关闭；旧包没有 managed processes |

不存在对象级 ACL、跨账号隔离或设备信任。App/CLI 的本机用户管理权限是明确的设计边界，不能当成不可信多用户服务部署。Web 仅回环监听，检查 Host/Origin/授权 token，无宽泛 CORS。MCP stdout 保持 JSON-RPC，诊断走 stderr。

记录保存成功只代表领域版本已落盘；计划成功代表通过当前校验的参数/文档；投递成功代表新 home 文件完成并 CAS 切换指针；模拟运行终态代表内置固定程序生命周期。以上均不证明真实 agent 已加载、账号已登录、会话正在运行或身份指引提供隔离。MCP 初始化/目录检查不证明工具调用获授权。

删除采用 tombstone，冲突显式引用全部 head，历史恢复新建 tombstone 的子版本，不擦除旧历史。投递/回滚保留所有 generation 与外部改动；启动复核源版本、映射和文件，未结束的模拟运行阻止更改选择。监管者丢失后的 recover 不杀保存 PID、不接管、不自动重启，termination_verified=false。发布取消/超时可能已到达远端，以 unknown 显示并在重试重新拉取；没有强推或时钟选赢家。这些由隔离回归验证，不承诺应对恶意同用户进程或所有断电情形。

## Air 与源码差异

最后成功交付的 Air 包：`Continuo-Demo-0.7.0-d22bfb0`，commit `d22bfb0cf94dbe8a56ca4b712b4e97b0c9249e19`。本轮只读 SSH 核对连接超时，未再次确认当前进程、窗口或安装文件，也未部署修复。

- Air 基线已有六领域记录、能力文本、MCP 本机映射/注册检查界面、会话计划和同步/冲突/删除恢复界面；Web 同步/probes 权限保持关闭，没有配置真实存储。
- 后续源码新增单个 MCP 的受管 home 投递/回滚和内置模拟生命周期，修复继承文件描述符延迟释放同步锁，并包含本轮安全与界面修复。Air 基线没有这些变化。
- 同为 0.7.0 不能判断功能一致。更新需按 commit 核对 App、CLI 与 Web 静态文件整套包；不复制活跃数据库、不自动提升原 Web 权限。视觉验收仍需用户在 Air 实际查看。

## 完成、未实现、未验证与依赖

已完成源码领域流程、三种 adapter 契约、共享接口/授权、加密因果事件同步、显式恢复和本机受管模拟运行。本轮本机通过 50 个 Rust、11 个 Web、25 个 UI 测试，renderer 构建、格式检查、独立 Tauri check 以及 arm64 App 构建/ad-hoc 签名验证。最终 commit 的远端 CI 状态见交付记录；本机通过不代替远端结果。未借用新上游代码或引入新许可。

未实现：真实 agent 进程执行、账号登录/凭据解析、对象级 ACL/OS 隔离、原生会话发现、完整内部状态迁移、skill 资源包、个人配置合并、HTTP MCP、设备配对/密码学撤销/密钥找回轮换、自动/增量同步。受管 generations 无清理，进程记录最多查询100条且无分页；本机 SQLite 会积累历史。GitHub 与临时 bare Git 是现有存储实现，不代表任意云存储已接入。公开分发仍缺 Developer ID、公证、安装/更新器和跨平台实测。

未验证：真实 GitHub 私有数据仓 + Mini/Air 端到端、真实三个 agent 加载/恢复/登录、当前源码的 Air 窗口视觉、跨平台运行与外部安全审计。

下一阶段停止在真实验收依赖：用户指定已有专用私有数据仓 URL，并批准新隔离目录、仅该仓读写、密钥生成/两端交接和单独试用 Web 权限；范围见 [readiness](readiness.md)。真实 agent 另需指定可信程序/版本、项目 cwd、账号与文件/网络范围和具体命令。旧违规历史迁移需单独明确范围，不自动改写。上述授权未到位，本阶段不继续接入账号、私人配置或无边界新功能。
