# 能力模块（0.4.0）

能力是可携带的文本上下文：规则或 skill。保存正文、说明、内容版本、声明的来源引用/版本/许可、适用 adapter ID 和依赖能力 ID。空正文的旧记录仍可编辑，作为待完善草稿；不会悄悄作为有效能力使用。扩展字段在编辑和检查标记中保留。

## 检查与应用

正文、名称、类型、内容版本、来源或依赖变更都会改变 SHA-256 内容摘要；`capability.review` 必须匹配读取时的因果 revision 和 digest。标记表示调用者确认这一版内容，不是签名、远端来源认证或执行权限。具有写权限的 agent 也可调用该接口，权限仍由 `Service::call` 的入口策略控制。

`capability.inspect` 返回正文、摘要、来源声明、依赖版本和失败原因。`capability.prepare` / `agent.prepare` 会检查所有依赖，按依赖在前的顺序去重展开。缺失、删除、并发版本、循环、未检查正文、空正文或目标 agent 不匹配时拒绝生成应用计划。身份关联的能力自动加入，可用 `capability_ids` 追加选择；每项应用包含精确 revision/digest。准备是只读快照，未来执行前仍需确认版本、运行时和权限。

三个 `AgentAdapter` 分别声明文本入口：Claude Code 的附加系统指引、Codex 的 developer instructions、Hermes 的初始用户提示。字面内容放入 argv，不执行 shell；不写原生配置、不运行脚本、不授予工具或文件权限、不声称身份隔离。适配器仍未通过真实登录运行时集成。

## 导入边界

App/Web 可粘贴正文；CLI/MCP 使用 `capability.import_text` 提交调用方已读取的文本。该方法只创建未检查记录，不自动访问 URL 或任意本机路径。来源仅接受不含凭据/查询参数的 HTTPS 或 `project:` 相对引用；来源版本与许可是导入者的声明，没有自动核验。不要把秘密、私人路径或原生运行状态放进正文；结构字段的秘密检查不能代替正文审查。

[Agent Skills 官方规范](https://agentskills.io/specification) 将 skill 定义为含 `SKILL.md` 的目录，可带脚本、引用与资源。本版只保留和应用其文本，不解析 YAML 元数据、不验证完整 skill 包，也不实现目录资源或渐进式原生加载。`allowed-tools` 等文本不会变成 Continuo 的授权。完整包验证、来源快照和原生安装需后续单独实现。

## 版本与冲突

`version` 是用户声明的内容标签；因果 revision 决定同步关系，不能用版本号或时间覆盖并发修改。同步继续交换加密不可变事件。编辑与删除的并发版本均可见，必须显式选择全部 heads 后整理；合并后的内容重新检查。同步导入保留缺失依赖或循环，检查时阻止使用，用户可以取消错误关联修复。图上限 128 个有效记录、64 层；合并能力正文上限 128 KiB；单项正文 64 KiB。

## 后续模块范围

- MCP：结构化 stdio/HTTP 定义、设备端命令/环境映射、凭据引用、可用性检查与三种注册计划；先完善可检查模型，再进行有授权的连接与安装。
- 会话：原生会话 ID 的设备作用域、任务/身份关联、生命周期记录与接续材料；保留本地会话状态边界，不跨 agent 迁移私有内部状态。
- 同步：用户仓库与密钥配置流程、清晰的状态/失败恢复、可见冲突处理、设备配对与密钥恢复设计；真实私有仓库/凭据和配置投递须由用户明确授权后实测。
